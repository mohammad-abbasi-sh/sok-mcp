# sok-mcp 🇹🇷

سرور MCP غیررسمی و **فقط‌خواندنی** برای **ŞOK** (sokmarket.com.tr) — یکی از زنجیره‌های بزرگ تخفیفی ترکیه: جست‌وجوی محصول، جزئیات محصول، دسته‌ها، گروه‌های کمپین و آمار قیمت.

> بخشی از «کارخانه‌ی MCP ترکیه» (پایپ‌لاین به سبک سپهر). هیچ وابستگی به ŞOK ندارد.

## برای ایجنت‌های هوش مصنوعی

```json
{
  "mcpServers": {
    "sok": {
      "command": "uvx",
      "args": ["sok-mcp==0.1.1"]
    }
  }
}
```

## ابزارها

| ابزار | توضیح |
|------|-------|
| `sok_search_products` | جست‌وجوی محصول با نام — `query`، ‏`limit` (۱ تا ۳۰، فقط صفحه‌ی اول) |
| `sok_get_product` | جزئیات محصول — `slug_or_url` (مثلاً `...-p-320230` یا URL کامل sokmarket.com.tr) |
| `sok_list_categories` | دسته‌های فروشگاه (نام، slug، id، url) |
| `sok_category_products` | محصولات یک دسته — `category` (slug یا URL)، ‏`limit` (۱ تا ۳۰) |
| `sok_list_promotions` | گروه‌های کمپین فعلی (`/kampanyalar`) |
| `sok_price_stats` | آمار قیمت یک جست‌وجو — تعداد، کمترین، بیشترین، میانه، میانگین (لیر) |

مثال (`sok_search_products` / «süt»): ۲۰۷ محصول؛ اولین نتیجه «Mis Uht Süt Yarım Yağlı 1 L» — ۴۳٫۵۰ لیر. مثال (`sok_price_stats` / «süt»): صفحه‌ی اول ۱۰ محصول، کمترین ۱۶٫۵۰ لیر، بیشترین ۸۸٫۵۰ لیر، میانه ۵۵٫۷۵ لیر.

نکته‌ها:
- قیمت‌ها به لیر ترکیه (TRY) هستند؛ سایت به سبک ترکی می‌نویسد (`43,50₺`).
- صفحه‌های جست‌وجو/دسته فقط صفحه‌ی اول را برمی‌گردانند (~۲۰ محصول)؛ `total` همه‌ی تطابق‌ها را گزارش می‌کند.
- داده: صفحات عمومی sokmarket.com.tr — بدون لاگین، بدون کلید، فقط‌خواندنی.

## قوانین

غیررسمی و فقط‌خواندنی — بدون لاگین، بدون کلید، بدون نوشتن. تست‌ها: آفلاین با فیکسچر + تست زنده (۱۵/۱۵ سبز).
